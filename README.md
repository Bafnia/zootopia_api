# Zootopia API

Generates a simple website based on animals fetched from the API Ninjas Animals API.

## How to run

1. Install dependencies:
   pip install -r requirements.txt

2. Create a `.env` file in the main folder:
   API_KEY=YOUR_API_KEY

3. Run the program:
   python3 animals_web_generator.py

4. Open the generated file `animals.html` in your browser.
